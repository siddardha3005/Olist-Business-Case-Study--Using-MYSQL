# Olist-Business-Case-Study--Using-MYSQL
• Analyzed 100K+ Brazilian e-commerce orders to evaluate sales trends, customer distribution, delivery performance, and payment behaviour using advanced SQL techniques 
• Built complex SQL queries using CTEs, window functions, aggregations, and joins to calculate MoM growth, revenue trends, freight costs, and state-level performance metrics 
• Identified 1.2% order cancellation/unavailability rate, highlighting operational improvement opportunities and cost reduction strategies 
• Determined states with highest freight costs and longest delivery times, recommending logistics optimization to reduce delivery time by 15% 


Tools and Databases used:
MYSQL


The data is available in 8 CSV files:

customers.csv
sellers.csv
order_items.csv
geolocation.csv
payments.csv
reviews.csv
orders.csv
products.csv
By analyzing this extensive dataset, it becomes possible to gain valuable insights into Olist operations in Brazil. The information can shed light on various aspects of the business, such as order processing, pricing strategies, payment and shipping efficiency, customer demographics, product characteristics, and customer satisfaction levels.
